# 90 秒展示脚本：EventLens MVP

> 演示工具：任意电脑浏览器。请先打开已部署的 Web URL，录制 90–120 秒屏幕视频。

**00–12 秒｜产品定位与摘要入口**

打开 AI 投研助手，输入“双成药业之前收购奥拉股份的事件，现在怎么样了？”。展示结论卡片：已终止、关键来源和关联股票。说明：“我们追踪的是持续演化的投资事件，而不是简单新闻聚合。”

**12–32 秒｜完整证据时间线**

点击“查看完整证据链”。展示顶部简洁事件状态、关联标的及投资影响。左侧纵向时间线，右侧节点详情。点击 2024 年 8 月与 9 月节点，展示不同历史阶段、原始来源和四类时间。

**32–46 秒｜证据核验机制**

在右侧指出“事实性主张 / 观点 / 推测 / 传闻”四类信息性质与证据质量分数。讲解：来源权威性 40%、直接性 25%、独立性 15%、时间 15%、完整性 5%。强调不同阶段 ≠ 事实冲突。

**46–70 秒｜核心链路：历史回放 + 版本**

点击“关注事件”，再点“历史回放”，按披露顺序点击“导入下一条”。展示筹划中 → 预案披露 → 已终止，版本记录只在关键变化时创建。展示新证据引发事件结论修订的日志。

**70–86 秒｜通知和风险**

打开通知，看到终止事件触发重大变化，点击回到事件结论版本。说明非官方手动材料不会冒充正式公告，重复转载不累计高权重。

**86–100 秒｜总结与边界**

说明产品是单事件 MVP，默认规则模式；若托管环境配置 OpenAI API 可以进行真实 LLM 结构化抽取；无全市场 7×24 实时监测，不虚构行情和预测。

**结束语**：“EventLens 让每条结论有依据，每次变化有解释。”
