## 2. 浏览器端交互测试

使用本地渲染方式，在浏览器中真实执行 JS 代码与点击事件：

- AI 投研助手首页可查看简洁卡片。
- 点击“查看完整证据链”进入单页事件详情。
- 时间线默认显示四个公开资料节点，点击可更新右侧核验详情。
- 导入一条市场传闻后，节点数从 4 → 5；事件已终止状态不被覆写。
- 390 px 手机界面没有横向溢出。
- 页内未发现 JavaScript 异常。

> 浏览器测试通过页面内代码注入进行，因为当前隔离环境限制浏览器访问 localhost；不是远程公网 URL 验证。

## 3. 数据 / 接口异常的处理

| 异常 | 系统行为 | 验证状态 |
|---|---|---|
| API key 未配置 | 返回非成功响应，浏览器退回规则抽取 | 逻辑已编码；未调用 Netlify 线上端点 |
| LLM 服务超时 / 非 2xx | 不展示虚构模型结果，退回规则抽取 | 逻辑检查；线上需进一步压测 |
| 缺少可验证的原文 URL | 仍可存档，但标记未经独立核实 | PASS |
| 用户输入非法日期 / 空内容 | 拒绝入库并明确错误 | PASS |
| 重复网页文章 | 阻止全文完全重复的导入 | PASS |
| 实体不清或新交易 | 标记待审核 / 新事项，不强制并入旧事件 | PASS |
| 暗示交易继续的传闻 | 可展示为未经核实主张，状态仍以已核对披露为准 | PASS |

## 4. 合规边界

- 无自动交易、证券买卖建议或收益承诺。
- 真实公司披露和模拟测试材料严格区分。
- 不将报道市场反应等同于已证明的因果关系。
- 评分不当概率使用；“已核验”的含义是有来源资料可核对，不代表外部审计保证。
- 源站可能失效、PDF 内容复杂，产品应显示错误或未知，不能编造数据。
