## 二、实际运行验证（不能杜撰）

- `npm test`：14/14 成功；覆盖业务链路、身份匹配、四类信息、五维评分、重复、未核实假公告、版本、关注通知、输入异常和合规。
- 前端渲染测试：浏览器脚本在离线页面注入 `data.js`、`engine.js`、`app.js` 并操作真实按钮；验证从摘要卡片进入时间线，点击节点，打开导入面板，输入市场传闻，界面实际新增节点，事件仍显示已终止；浏览器无 JS 异常。
- 移动宽度 390px：页面无横向溢出；移动布局时间线与节点详情上下排列。
- 外部 LLM API：**尚未执行真实密钥调用**，功能已提供并配有明确的离线退化策略，不报告假的模型准确率。
- 扶摇/iFinD MCP：**尚无已验证连接**，未接入真实实时行情。

## 三、重要防幻觉措施

1. 未核实手动材料无法伪造 `checked=true` 的官方来源资格。
2. 所有新增主张只保留来自用户导入文本中的连续 quote。
3. 系统不会用一条晚来的传闻改写已经有正式公告支持的终止结论。
4. 多媒体转载不按传播数量累计独立证据权重。
5. 事件发生时间不可凭公告日期猜测；未知时明确保留未知。
6. AI 数字评分只表示质量参考，不表示统计概率。

## 四、改进实验计划

- 整理手动标注的 30–50 个多来源主张组，分别计算分类一致率、事件误合并率、冲突误报率、原文引用准确率。
- 对比规则抽取与 LLM 抽取效果；单独统计否定、条件、事件时间与来源独立性的错误。
- 接通 iFinD / 扶摇后重复数据许可与数值可追溯验证。
