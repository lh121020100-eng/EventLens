# EventLens UI V1.1 — 前端优化记录

日期：2026-10-30

## 用户需求
- 节点详情不再展示“证据质量参考分 /100”与五维百分比；只需简洁核验结论和可点击原始资料。
- 保留单页顶部概览与 50:50 纵向时间线/节点详情；不改变分析引擎内部权重。
- 保留真实材料与用户输入待核实材料的区分。

## 修改
- 节点详情核验结论仅显示“有原始公开材料支持”等明确状态；对观点、推测、传闻或未核实来源显示必要的判断边界。
- 去掉重复的“支持性主张”等细碎标签，保留事实性主张/观点/推测/传闻的类型信息。
- “原文摘录”统一放入“原始证据”区，贴近外部资料链接。
- 侧栏“证据评分规则”调整为“核验原则”，不显示百分比。
- 移除对在线字体资源的依赖，离线预览更稳定。

## 本轮实际验证
- `npm test`：15/15 通过，包括引擎、合规及前端文本回归断言。后端测试中无密钥响应期望与当前接口定义同步校正。
- Chromium Playwright：桌面端和手机端检查，详情、原文摘录、四类时间与原始证据链接存在；桌面端节点切换成功；页面无 JavaScript 错误，手机无横向溢出。
- 手动导入传闻：核验结论显示“传闻尚未获得独立证实”，原交易状态仍为“已终止”，原文链接缺失时给出明确提示。
